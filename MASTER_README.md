## Important
- Most projects are intentionally tiny: focus on the flow, not production architecture.
- LLM projects use **local Ollama** where practical, so no paid API key is required.
- Kafka and Airflow require their own local/server setup.
- Tesseract requires the Tesseract OCR engine in addition to the Python package.
- Some rapidly evolving libraries may change APIs. Each project contains its own README and requirements.txt.
- For each folder: create a virtual environment, install requirements, then run the script.

## Suggested study method
For every project:
1. Read README.md.
2. Run it.
3. Change one line.
4. Run again and observe what changed.
5. Explain the flow in your own words.
6. Only then move to the next project.
